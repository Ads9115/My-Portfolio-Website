A retro, interactive browser-based operating system built to showcase my graphics programming and game development portfolio. Migrated to modern **React 19 + TypeScript + Zustand + Vite** with 100% retro visual fidelity.

## Features
* Interactive Desktop: Draggable windows, clickable icons, and a working Start Menu.
* Custom Mini-Apps: A functional command prompt, an arcade Pong game with AI, a software 3D rasterizer, and a pixel paint tool.
* Living Environment: Animated synthwave background, wandering desktop pet, and physics-based interactions.

## Development & Usage

```bash
# Install dependencies
npm install

# Start local development server with hot-reload
npm run dev

# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
